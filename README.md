Collection of notebooks for exploration, preprocessing, and machine-learning assignments.

## Notebook folders

- `computer-vision/` — computer-vision assignments
- `eda/` — exploratory data analysis
- `nlp/` — natural-language-processing assignments
- `preprocessing/` — data-preprocessing workflows
- `time-series/` — time-series experiments

## Setup

```bash
pip install -r requirements.txt
```

## Open notebooks

```bash
jupyter notebook
```

The notebooks can be opened in Jupyter, VS Code, or Google Colab.
